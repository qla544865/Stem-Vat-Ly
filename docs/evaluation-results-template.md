# Mẫu tổng hợp kết quả đánh giá

**Trạng thái: chưa tiến hành đánh giá thực tế.** Các ô trống không phải số 0. Không sử dụng kết quả test kỹ thuật như điểm đánh giá học tập.

## Bối cảnh

- Phiên bản/commit và URL: ______
- Thời gian, thiết bị, trình duyệt, máy chiếu: ______
- Cách tuyển nhóm và số người thực tế theo vai trò: ______
- Nhiệm vụ, điều kiện, cách phân nhóm (nếu có): ______
- Các sai lệch so với kế hoạch: ______

## Khả năng hoàn thành

| Nhiệm vụ           | Số người thực hiện | Độc lập | Có hỗ trợ | Chưa hoàn thành | Trung vị thời gian thao tác | Thời gian chờ đo |
| ------------------ | ------------------ | ------- | --------- | --------------- | --------------------------- | ---------------- |
| Chiều dài con lắc  |                    |         |           |                 |                             |                  |
| Đo và ghi kết quả  |                    |         |           |                 |                             |                  |
| Challenge (ghi ID) |                    |         |           |                 |                             |                  |
| Động lượng         |                    |         |           |                 |                             |                  |
| Trình chiếu        |                    |         |           |                 |                             |                  |

Tỉ lệ hoàn thành = (độc lập + có hỗ trợ) / số người thực hiện. Báo cáo riêng tỉ lệ độc lập; nêu mẫu số và loại trừ nhiệm vụ không thực hiện. Tách hỗ trợ do người quan sát với tự dùng hướng dẫn.

| Câu hỏi               | Số phản hồi hợp lệ | Số chọn 1/2/3/4/5 | Trung vị | Chưa dùng/Không áp dụng |

Không cộng ô không áp dụng vào thang Likert. Chỉ tính tổng hợp sau khi có dữ liệu thật và nêu cách tính.

## Diễn giải và giới hạn

- Dữ liệu quan sát trực tiếp: ______
- Nhận xét/suy luận của nhóm: ______
- Khác biệt giữa nhóm nếu có (cách phân nhóm và sai lệch): ______
- Giới hạn mẫu, nền kiến thức, thiết bị, ảnh hưởng người quan sát/thứ tự: ______
- Điều chưa đo được: ______
- Quyết định và lần đánh giá tiếp theo: ______

Không kết luận PhyLab làm tăng kết quả học tập hoặc gây ra khác biệt chỉ từ mức hài lòng, một buổi dùng thử hoặc so sánh nhóm thiếu kiểm soát.
